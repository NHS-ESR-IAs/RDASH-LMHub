Facilitator Support: How to link your training session to the Learning Hub

Guidance for Trainers, Educators & Line Managers to facilitate and record sessions

1
Request the Form:
Request the form from your Backbone/Care Groups LHD representative.
2
Complete & Return:
Complete the form (example shown below on page 2) and email to your LHD representative.
3
Session Published:
Your session is created on ESR, displayed on the Learning Hub and added to the calendar.
Tips for completing this form:
Course name/topic:
Write the main name of the course. This is the overall “group name”.
Example: Poverty Proofing, Autism
Class title:
Write the full title of the class.
Example: “Poverty Proofing: Children’s Care Group only”, “Autism: Beginners guide to Autism”
Class date:
Ensure the date matches one of the Learning Half Day dates.
Class time:
Ensure the time matches a Learning Half Day time.
Duration:
Write how long the lesson will last and add the times.
Contact details:
Write the facilitators full name and email address.
Venue:
State how the session will be delivered:
  • in person – include the full address and meeting room name if applicable.
  • online via Microsoft Teams
  • hybrid if both in person and online
Target audience:
State who the session is for. Ie LHD offer to all colleagues.
Is it for the whole trust or just one care group or service?
Class description:
Write a short sentence/paragraph explaining what the session is about.
Example: This session teaches how to identify asbestos, understand the risks, and follow the correct procedure.
Recording for Video Vault:
Confirm if the session will be recorded and added to the Video Vault.
